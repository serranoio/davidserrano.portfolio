# The System Dance

You have coded a system that dances when

It can move to user's requirements without needing to be rewritten. 

It can hit the beat again & again thru extensibility.

It stays on beat every time with 100% reliability

A bug is your code misstepping to the beat. Just like how failures are a natural part of life, bugs are natural. They are to be surfaced as they are opportunities for growth.
